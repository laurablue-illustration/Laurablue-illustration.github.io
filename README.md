# Laura Blue — Portfolio

Web de portfolio para Laura Blue, ilustradora.

## Estructura
- `index.html` — página principal
- `css/styles.css` — diseño
- `js/script.js` — menú y filtros
- `images/` — aquí van las ilustraciones originales

## Publicar con GitHub Pages
1. Crea un repositorio llamado `TUUSUARIO.github.io`.
2. Sube todos los archivos de esta carpeta al repositorio.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. GitHub publicará la web en `https://TUUSUARIO.github.io/`.
